# True-crime-scriptwriter

Working repo for true crime scriptwriting jobs and trials.

- [`latunski-trial/`](latunski-trial/) — trial script for the Red Tree Crime scriptwriter application (Mark Latunski case), with transcripts, sources and notes.
- [`portfolio/`](portfolio/) — portfolio of spec samples (full Latunski episode script, research dossier and clip bank, interrogation breakdown, YouTube-safe style guide, index page).
- [`tools/`](tools/) — helper scripts (Google Form extractor, AssemblyAI transcription poller, script and portfolio builders).

Media files (video/audio) are not stored here; they live in the channel's Drive folders linked from each case's README.
